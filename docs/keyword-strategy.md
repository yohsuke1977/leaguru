## 4. 戦略

### 原則
**Leaguruの最大のSEO資産は、記事ではなくテナントサイトそのもの。**
テナントが1つ増えるごとに「＜地域＞＋リーグ名」の指名検索を1つ獲得し、
そのフッターから leaguru.jp へ送客される（実装済み）。
SBL単独で四半期608クリック＝記事30本の34倍。

### 施策（優先順）

#### ① 全国の草野球リーグ ディレクトリ（最優先・新規）
`leaguru.jp/leagues/` に**実在する草野球リーグの一覧**を地域別で作る。

- 根拠: 「名古屋サタデーベースボール」301表示が示すとおり、地域リーグの指名検索は実在する
- 各リーグ: 名称・地域・活動曜日・公式サイトリンク（Leaguru利用有無は問わない）
- 一次情報として価値があり、**リーグ運営者への営業リストそのものになる**
- 「＜地域＞ 草野球 リーグ」「＜地域＞ 草野球 チーム 募集」の受け皿
- 掲載されたリーグ側から被リンク・言及が発生しうる（GEO対策の「第三者言及」にも効く）

#### ② Ninepage LP を「野球チーム ホームページ作成」で上げる
- 現状84位＝タイトル・見出し・本文に語が入っていない可能性が高い
- LPの`<title>`/H1/本文をこの語に合わせる
- 関連語（「野球チーム サイト 無料」「草野球 チーム ホームページ」）も同時に

#### ③ 既存の当たり3記事を強化
1ページ目にいるので、**内容を厚くすれば上位1〜3位を狙える**。
- `excel-standings-limits`（6.6位）
- `league-rules-howto`（7.9位）
- `attract-new-teams`（6.8位）
新規30本より、この3本を直す方が効く。

#### ④ 記事の自動生成は週3→週1に減らす
止めはしないが、空振りが27/30なので本数を減らし、テーマを
「運営者ノウハウ」から**「地域リーグ紹介」「チーム向け実用（ルール・スコア・道具）」**へ寄せる。

## 【重要な訂正】2026-08-20 — 半年データで見直し

初版（8/6）は**3ヶ月窓で3記事しか見ておらず、結論を誤っていた**。
半年（2026-02-20〜08-20）で取り直した実測は次のとおり。

| | 初版の記述 | 実際 |
|---|---|---|
| 記事の表示 | 「30本中27本が表示ゼロ」 | **25ページが表示あり・ブログ計591表示** |
| 最大の記事 | excel-standings-limits 29表示 | **tournament-bracket-howto 162表示** |
| サイト合計 | 181表示 | **779表示・34クリック・平均7.0位** |

### 本当の問題は「表示」ではなく「CTR」

上位記事は **6〜8位＝1ページ目**にいるのに**クリックがほぼゼロ**。
原因は検索意図とタイトルのミスマッチだった。

| 実際の流入クエリ | 表示されていたタイトル |
|---|---|
| トーナメント表 bye 意味（17表示・9.1位） | 草野球のトーナメント表、参加チームが**半端でも組める？** |
| 野球 勝ち点とは | 草野球リーグの**順位決定方式の選び方** |
| 雨天順延とは / 試合順延とは | 草野球 雨天中止・**順延の判断基準と連絡フロー** |
| 草野球スパイク 規定 | 草野球リーグの**使用球・用具統一ルール** |

**検索者は「運営者」ではなく「用語の意味を知りたい人」だった。**
「意味を知りたい人」に「運営の設計方法」を出していたのでクリックされない。

### 需要が確認できたクエリ群（半年）

```
bye 関連の合計          約49表示   ← 最大クラスタ
トーナメント 山とは        3表示
野球 勝ち点とは            2表示
雨天順延とは/試合順延とは   4表示
草野球スパイク 規定        3表示
リーグとトーナメントの違い  2表示
```

すべて **「◯◯とは」「◯◯の意味」「◯◯規定」型**。
一方、初版で狙っていた汎用ノウハウ語（「草野球リーグ」2表示）はやはり需要が無い。

### 対応（実施済み・8/20）

1. 上位3記事に**冒頭の定義ブロック**を追加し、タイトルを検索意図に寄せた
   （運営者向けの主題は保持。両方の意図を満たす構成にした）
2. 自動生成のテーマキューが空だったので、**実測クエリベースで10件補充**
   （`content/blog-queue.json`。選定基準を `_comment` に明記）
3. 8/17に自動生成された `tournament-bye-meaning-bracket-guide` が
   **Googleに未発見**だったのでIndexing APIで通知

- 見る指標は**表示回数ではなくCTRと平均掲載順位**
- 目標: 上位記事を6〜8位 → **3〜5位**（CTRが跳ねる帯）
